# Architecture decisions

Record decisions that affect the project's structure, dependencies, deployment,
or long-term maintenance. Routine implementation choices do not need a record.

Use a numbered filename such as `001-application-framework.md` and include:

- Title and date
- Status: proposed, accepted, or superseded
- Context and requirements
- Decision and rationale
- Alternatives considered
- Consequences and follow-up work

When a decision changes, add a new record and mark the previous one superseded.
